# Созвездие — конструктор компетенций будущего инженера

Квиз профориентации для 5–11 классов: 14 инженерных направлений, Hard и Soft skills, «Индивидуальный план развития инженерных компетенций».

## Как опубликовать на GitHub Pages
1. Создайте репозиторий, например `sozvezdie`, и загрузите в него `index.html` и папку `lib/` (структуру не меняйте).
2. Settings → Pages → Branch: `main`, папка `/ (root)` → Save.
3. Через минуту сайт откроется по адресу `https://<логин>.github.io/sozvezdie/`.

## Файлы
- `index.html` — весь сервис: разметка, стили, данные и логика (без сервера).
- `lib/html2pdf.bundle.min.js` — сохранение плана в PDF (MIT).
- `lib/jsqr.min.js` — сканирование QR-кодов в дашборде (Apache-2.0).
- Генератор QR-кодов qrcode-generator (MIT, © Kazuhiko Arase) встроен в `index.html`.

## Полезные адреса
- `…/index.html?k=7.5` — ссылка для класса с меткой «7.5».
- `…/index.html#dashboard` — дашборд класса.
- `…/index.html#teacher` — экран «Провести в классе» с QR-кодом.
