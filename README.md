# Созвездие — конструктор компетенций будущего инженера

Тест по профориентации для 5–11 классов: 14 инженерных направлений, Hard и Soft skills, «Индивидуальный план развития инженерных компетенций».

Сайт: https://abrinpro.github.io/Sozvezdie-5-11/

## Как опубликовать на GitHub Pages
1. Загрузите в репозиторий `index.html` и папку `lib/` (структуру не меняйте).
2. Settings → Pages → Branch: `main`, папка `/ (root)` → Save.

## Файлы
- `index.html` — весь сервис: разметка, стили, данные и логика (без сервера).
- `lib/html2pdf.bundle.min.js` — сохранение плана в PDF (MIT).
- `lib/jsqr.min.js` — сканирование QR-кодов на странице «Результаты класса» (Apache-2.0).
- Генератор QR-кодов qrcode-generator (MIT, © Kazuhiko Arase) встроен в `index.html`.

## Сбор результатов
- Ученик нажимает «Отправить результаты учителю» — открывается Яндекс Форма «Созвездие 5–11 — результаты» с кодом результата в скрытом поле `code`. Остаётся нажать «Отправить». Имя не передаётся.
- Учитель в форме: «Ответы» → «Скачать» (XLSX или CSV) и перетаскивает файл на страницу «Результаты класса».
- Запасные способы: «QR для учителя», ссылка или файл с результатом.
- Адрес формы задан в `index.html`: `DATA.meta.collect.formUrl`.

## Полезные адреса
- `…/?k=7.5` — ссылка для класса с меткой «7.5».
- `…/#dashboard` — результаты класса.
- `…/#teacher` — экран «Провести в классе» с QR-кодом.
